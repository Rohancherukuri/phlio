# Foxy Rive animation

`foxy.riv` is Foxy's Rive file. `FoxyRive`
(`lib/design_system/widgets/foxy_rive.dart`) loads it once per launch and
uses it for onboarding and for animated stickers (`foxy:<outfit>:<mood>`)
in Social and Rooms. If it can't be loaded, Foxy falls back to his PNGs and
GIF loops on a Flutter motion rig.

It is generated by `scripts/media/build_foxy_riv.py` from the original art,
which is never redrawn:

- poses: `assets/images/foxy/foxy_*.png`
- outfits: `assets/stickers/sticker_costume_*.png`
- props (sparkles, confetti, Zzz, hearts, thought dots, rain, snow, smoke
  puffs) are small brand-colour sprites drawn by the script.

Rebuild after changing any of that art:

    python scripts/media/build_foxy_riv.py

You can also open `foxy.riv` in the Rive editor and refine it; keep the
state machine contract below so the app keeps driving it.

## Artboard `Foxy` (400 × 400)

    lean → hop → shake → breath → pose → classic (8 poses) / wardrobe (11 outfits)
    props per mood and per outfit, smoke puffs, shadow

## State machine `Foxy`

| Input    | Type    | Meaning |
|----------|---------|---------|
| `mood`   | Number  | 0 wave, 1 think, 2 celebrate, 3 explore, 4 sleep, 5 hello, 6 curious, 7 noPeeking, 8 focused, 9 cozy, 10 love |
| `outfit` | Number  | 0 classic, 1 explorer, 2 hoodie, 3 space, 4 samurai, 5 wizard, 6 chef, 7 student, 8 business, 9 rainy, 10 winter, 11 traveler |
| `lean`   | Number  | -100 (lean left) … 100 (lean right), a 1D blend |
| `hop`    | Trigger | Jump with squash and stretch |
| `shake`  | Trigger | Head shake |
| `poof`   | Trigger | Smoke puff (fired when the outfit changes) |

Layers run together: **Mood** (320 ms crossfades, motion and props per mood),
**Outfit** (260 ms crossfades; rain, snow, wand sparkles and stars belong to
their outfits), **Breath**, **Lean**, **Reactions** (hop / shake) and
**Poof**. The numbers match the `FoxyMood` and `FoxyOutfit` enum order.

Classic poses change with the mood; an outfit is one pose, so with an
outfit on, the mood only changes his motion and props.
