# Foxy Moves — Discord sticker pack

24 animated Foxy stickers, rigged from Phlio's own Foxy art
(`scripts/media/foxy_rig/`). `preview.gif` shows them all moving.

`discord/foxy_<name>.png` are animated PNGs (APNG) that meet Discord's
sticker rules: **320 × 320 px, ≤ 512 KB, transparent background**.

## Upload to a Discord server

1. Server Settings → **Stickers** → **Upload Sticker**.
2. Pick a file from `discord/`, give it a name, a related emoji and a short
   description (suggestions below).
3. Sticker slots depend on the server's Boost level (5 at level 0; more with
   boosts).
